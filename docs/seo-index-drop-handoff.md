## ★2026-10-03 追加調査で前提が変わった（必ず読む）

**1. 「−76%」は移転直後のピーク比だった。** 新旧合算の表示/日（GSC API・週平均）:
移転前（7月〜8月中旬）**170〜260** → 移転直後（8/31・9/7の週）**約620**（新ドメインの一時的な上乗せ）
→ 9/14週 255 → 9/21週 **101**。**移転前の平常水準（約200/日）比で約−50%**。
旧ドメインの表示も 9/14 以降 170→92 に落ちているので、移転による分散だけでは説明できない＝低下は本物。
**再測定の基準は「移転前の約200表示/日」に置く。**

**2. 一覧型ページに偏って落ちた。** 101枚の内訳を母数で割ると:
年代 JA 10/11（91%）・EN 8/11（73%）／アーカイブ JA・EN とも／写真家 JA 41/426（10%）・EN 28/426（7%）／
運動 3/70・国 4/70。検出-未登録204枚はほぼ全部が写真家ページ。
年代・アーカイブは**旧ドメインでは表示0**で、移転後に初めて表示（年代23.7/日・アーカイブ39.6/日）→
最後の表示は 9/16〜9/19 に集中。＝「新ドメインで一度入れてもらえた一覧型ページが9/15前後にまとめて外された」。

**3. 一覧型ページは本文の大半がサイト内の使い回し。** 他ページと重複する文の割合（JA）:
年代 81% ／ アーカイブ 79% ／ 運動 64%（運動は独自解説が多く、落ちた率も低い）。
botっぽい見た目ではなく「独自の文章が少ない」と判定されたと読むのが自然。
ただし写真家ページも一部落ちているので、全体像は「サイトの信頼量不足で枠が絞られ、独自文の少ない一覧型から先に切られた」の2層。

**4. 外部の状況。** 9/15〜16 に業界全体で大きな順位変動（Google未発表）。9/23〜 に9月スパムアップデート
（テンプレート的・大量生成・AI生成と見られるページが影響と報道）。このサイトの低下開始は9/15の変動と一致。

**5. AI開示ブロック説は弱まった。** 全ページ同文なのに、ページの型で落ち方が大きく違う。Bingも無傷。

### 方針（Daisuke 2026-10-03 合意）

回復だけのための即効策はもう無い。サイトを普通に良くすることが回復策。
1. 新規追加より**既存ページ（落ちた101枚・未登録204枚）を厚くする**のを優先。追加は今まで通り少しずつ
2. **年代ページは1〜2枚で試す**（その年代固有の解説を厚くし、使い回し比率を下げる。カードは減らさない）→ 数週間様子を見る
3. 外部リンクは徐々に（note から個別写真家ページへ直接。リンクだけの投稿の量産はしない）
4. 10月下旬に再測定（基準＝移転前の約200表示/日）

## 残っている仮説

1. **サイトの信頼量に対してページ数が多すぎる**（最有力）
   ドメインは5週間、ページ1,000枚、外部リンクほぼゼロ。BWTも「質の高いドメインからの被リンクが不足」と指摘。
   Googleが新規ドメインへ割り当てる索引量は被リンク・言及に依存する。旧ドメイン（2年運用）のほうが
   表示され続けているのも同じ説明で整合する。
2. **9/14〜9/19の大量改変**（4日で815ページ：出典番号621枚・EN表記76枚・JSON-LD 125枚・新規18名）
   時期は一致するが、リクエスト0/6で「一時的」説は弱まった。引き金ではあっても主因ではない可能性。
3. **AI開示ブロック**（2026-08-30に全1,023ページへ「本文執筆 — AI」を明記）
   相関のみ。証明手段なし。**扱いはDaisukeの方針判断**で、技術で決める話ではない。
   隠しても中身は変わらない点は伝え済み。
4. **Google側の非公開の変動**（2026年は発表なしの変動が常態化と報道）

## 次にやること（優先順）

### タスク1 — sitemap から開発用3枚を外す＋noindex（★2026-10-03 完了・push済。sitemap 1,028→1,025。`toptest-extracted.html` は iframe 中身なので `noindex, indexifembedded`）

**問題**: sitemap が読者向けでないページを「索引に入れてほしい」と申告している。

```
index-v51.html                 124KB  ★トップページと一字一句同じ title
design/toptest.html          19,425KB  ★19MB。スターマップの開発版
design/toptest-extracted.html   787KB  スターマップのiframe中身
```

`index-v51.html` はトップの旧デザイン版で**タイトルがトップと完全に同一**。
長く未解明だった「トップ `/` のクリック 22→10（−55%）」と関係する可能性がある。

**やること**
1. `scripts/generate_sitemap.py` の除外リストに `index-v51.html` と `design/` を追加
2. 3枚に `<meta name="robots" content="noindex">` を付ける（**ファイルは消さない**。
   スターマップは `design/toptest-extracted.html` をiframeで読んでいる）
3. sitemap 再生成 → **`<loc>` が 1,028 → 1,025 になることを確認**
   （**既知の罠**: 素で回すと `.claude/worktrees/` の複製でURLが膨張する。
   [[reference-sitemap-generator-pitfalls]] / `docs/generators-and-guards.md`）
4. `check_content_loss.py` → `preflight.py` → push → IndexNow は不要（Bingは無傷）

**これは「サイト全体の一括改変」には当たらない**（3ファイル＋sitemapのみ）。凍結対象外。

- **新プロパティの数字だけで判断すること**。旧プロパティに表示の9割が出ている
